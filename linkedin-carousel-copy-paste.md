3️⃣ EXECUTIVE FUNCTION

## SLIDE 5

What inclusive learning actually looks like:

ATTENTION
Before: 45-min dense module
After: 8-10 min focused units with breaks

COMMUNICATION
Before: Technical jargon
After: Plain language + visuals + examples

EXECUTIVE FUNCTION
Before: Vague deadlines
After: Checklists, milestones, visible progress

ACCESS
Before: Desktop only
After: Mobile + captions + downloadable PDFs

ASSESSMENT
Before: One-shot written test
After: Choice: write, perform, discuss
